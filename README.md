# swamp-software-factory-flow-metrics

[swamp](https://swamp-club.com) extension `@mgreten/software-factory-flow-metrics` — deterministic quality/reliability/flow metrics for `@swamp/software-factory` work items, rendered statically from recorded run data.

📖 **Extension documentation:** [extensions/README.md](extensions/README.md)

📦 **Install:** `swamp extension pull @mgreten/software-factory-flow-metrics`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable report extension lives under [extensions/](extensions/).
